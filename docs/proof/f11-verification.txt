9. THE ONE DEFECT FOUND AND FIXED DURING THE CUT
--------------------------------------------------------------------------------
The narrow arrangements' band placement was written as `.synergy-board__band
{ grid-column: 1 / -1 }` — specificity (0,1,0) — against wide placements
written as `.synergy-board__band[data-band="..."]` at (0,2,0). The bare
selector LOST, the Permanent band kept columns 7/11, and the five-track
template grew five implicit tracks it never sized. Measured before the fix:
cellW 88.97 at 768 against a 151.50 demand, and 2.00 at 390.

Caught by measuring rather than by looking, and worth recording because a
green suite said nothing about it: no jsdom test can see a collapsed grid
track, and the arrangement is correct in the DOM at every width.

11. HOW THE BROWSER PROOF WAS SERVED
--------------------------------------------------------------------------------
NOT on the pinned 5173 origin. The dispatch forbids starting a dev server
there because every worktree shares that origin's localStorage and stale code
could strip fields from the operator's real saved builds. Served on
http://localhost:5111 instead (`npx vite --port 5111 --strictPort`), which is
a DIFFERENT origin and therefore a different localStorage store — the same
isolation F5.4 used at 5199/5201. The fixture was injected with
Page.addScriptToEvaluateOnNewDocument so it lands before any page script; the
operator's own 5173 store was never opened, read or written.
