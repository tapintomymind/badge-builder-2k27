# `src/data/` — the dataset

Read-only at runtime. Consumed as a bundled module import, never via `fs` or any
absolute path.

The shipped dataset is **generated**, not hand-edited. The checked-in source text
is the single place a number may be typed, and a test asserts that regenerating
from that source reproduces the shipped dataset byte-for-byte. This makes a data
refresh a one-file edit with a reviewable diff.

Note the honest limit of that guarantee: the generator RELOCATES transcription
risk into its abbreviation map rather than removing it. The two controls that
close it — an alias-map bijection test and a 13-badge spot-check against
literals hand-transcribed from the sealed requirements doc — are ship gates in
the test suite (`tests/alias-bijection.test.ts`, `tests/spot-check.test.ts`).

**Never invent data.** An unknown value stays unknown (`null`) — it is never
guessed, rounded, or filled in from intuition.

## Files

- `badges.source.txt` — the sealed seed's 53-badge listing, VERBATIM. Beware:
  U+2014 `—` is both the name/attr separator and the null-threshold token,
  while heights use U+2013 `–`. Do not "clean up" the separators.
- `badges.json` — generated by `npm run generate:badges`. Never edit by hand;
  a byte-equality test enforces this. Carries provenance (`dataVersion`,
  `gameVersion: null` until published, `confidence`).
